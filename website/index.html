Main tool

Each level is solved in your own terminal. The answer is never in a file: it is something Nix computes, builds or fixes for you.

A level is a short job

Level 00 starts with a file that looks like it hides a secret. It does not. It is a program, and the flag is what it evaluates to.

  1. Receive

    wargame start prepares a scratch directory and prints the goal. Hints come one at a time with wargame hint N.

  2. Do

    Do the real Nix thing: evaluate an expression, build a derivation, fix a broken build. Level 00: evaluate flag.nix and keep the string it produces.

  3. Submit

    Send the result with wargame submit N 'FLAG{...}'. A correct flag unlocks level N+1.

Level 00, in your terminal

$ ./wargame doctor        # check your Nix setup
$ ./wargame start         # show level 00 and prepare it
$ nix-instantiate --eval flag.nix
$ ./wargame submit 00 'FLAG{...}'

Without flakes: git clone https://github.com/NeanderTeam/nix-wargame.git && cd nix-wargame and use ./wargame. Commands: status start [N] [--fresh] show N hint N submit N FLAG where [N] env doctor reset.

Sealed before it ships

What the game will not do to your machine, and what it asks of you.

  • No root

    No level needs sudo or changes system config. /etc/nix is never touched.

  • Your store, your call

    Builds add paths to your normal Nix store. The game never runs garbage collection and never touches your real profile. Remove what you like later with your own nix-collect-garbage.

  • Network is marked

    Levels that need it say Network: YES in their goal and only talk to cache.nixos.org and github.com. Pinned nixpkgs is about 40 MB the first time.

  • Flags are hashed

    Each level ships only a flag.sha256, never the flag itself. Solutions live apart in solutions/, so a public copy can leave them out.

  • Honor system

    Level locking is a local bash script. You can edit the progress file or read the solutions. The only person you cheat is yourself.

Run it as a class or a CTF

8 levels per 90-minute session, one tier at a time.

Everyone plays locally, so the progress file is theirs. To track a group, ask for the wargame status output, or have players submit the flag of a chosen level to your own form.

Flags are identical for every player. Share them only after the event, or use a different pin per cohort. To self-host, fork the repo, change the owner in the run command and point students at nix run github:<your-org>/nix-wargame.
