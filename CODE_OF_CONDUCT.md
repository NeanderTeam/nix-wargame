# Code of Conduct

Be kind, be patient, assume good faith. This is a learning project; questions
that look basic are welcome.

- No harassment, discrimination or personal attacks.
- Do not post level solutions or flags in public issues, pull requests or
  discussions. Use the spoiler-free hints, or mark the thread clearly as a spoiler.
- Maintainers may edit or remove contributions that violate this and may
  restrict participation for repeated violations.

Report problems by opening an issue at
https://github.com/neanderteam/nix-wargame/issues (or contact the maintainers
through the organization page https://github.com/neanderteam if the report
should not be public).
